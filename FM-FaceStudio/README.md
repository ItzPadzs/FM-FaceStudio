# FM FaceStudio

Open-source desktop tooling for researching, analysing and eventually generating Football Manager 2026 faces from a single photograph.

**Current release:** Alpha 0.1 — Foundation

## Included

- Professional PySide6 desktop shell
- Sidebar navigation
- Dark and light themes
- Persistent settings
- Structured logging
- FM26 installation detection
- Modular AI, mesh, asset and project layers
- Automated core tests

## Start on Windows

1. Extract the repository.
2. Double-click `INSTALL_AND_OPEN.bat`.
3. After first setup, use `RUN.bat`.

The current build is read-only and does not modify Football Manager.

## Tests

```powershell
python -m pytest
```
